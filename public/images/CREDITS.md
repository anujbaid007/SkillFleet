Both have been centre-cropped to 1600x1067 and re-encoded as JPEG for the web.
Cropping makes the CC BY-SA image a derivative work, so that licence travels
with it.

If you would rather carry no attribution obligation at all, replace
`kid-raising-hand.jpg` with a Pexels or Unsplash photo (both permit free
commercial use with no credit and handle model releases) and delete its row
above. The filename is referenced in six components, so swapping the file is
the only change needed.
